# Session Index

This folder stores the materials from each project session or presentation.

## Session 1 - Understanding the Paper

Folder: `session-01-understanding-paper/`

Focus: understanding the original AMFU-Net paper, its fusion stage, segmentation architecture, dataset, reported metrics, and dataset access limitation.

## Session 2 - Preprocessing Pivot

Folder: `session-02-preprocessing-pivot/`

Focus: explaining why the original fusion stage cannot be reproduced with public datasets, and why the project pivots to single-image enhancement using speckle despeckling and CLAHE.

## Session 4 - Enhancement Pipeline

Folder: `session-04-enhancement-pipeline/`

Focus: explaining ultrasound speckle noise, despeckling, CLAHE, and why the order should be despeckling first, then contrast enhancement.

## Session 5 - Current Progress

Folder: `session-05-current-progress/`

Focus: current implementation progress across preprocessing, model training, and demo/inference.

Included materials:

- Preprocessing explanation
- Training explanation
- Demo explanation
